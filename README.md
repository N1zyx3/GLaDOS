# 🤖 GLaDOS Interactive Voice Assistant (LLM + STT + TTS)

Интерактивный голосовой ассистент с характером и оригинальным русским голосом **GLaDOS** из вселенной Portal. Скрипт умеет слушать пользователя по кнопке (Push-to-Talk), общаться через локальную языковую модель и отвечать аутентичным синтезированным голосом.

---

## 🎧 Демонстрация озвучки (Сравнение)

Вы можете оценить качество и сходство синтезированного голоса с оригиналом:

* **Оригинальный голос GLaDOS из игры:** [GLaDOS_original.wav](https://github.com/N1zyx3/N1zyx3/raw/refs/heads/main/files/GLaDOS/README.md/GLaDOS_original.wav)
* **Синтезированный голос (Модель TeraTTS):** [GLaDOS_ttsl.wav](https://github.com/N1zyx3/N1zyx3/raw/refs/heads/main/files/GLaDOS/README.md/GLaDOS_ttsl.wav)

## ✨ Основные фичи

* **🎙 Голосовой ввод (STT):** Распознавание русской речи в реальном времени с помощью быстрой и точной модели `faster-whisper`.
* **🧠 Локальный ИИ:** Интеграция с вашим персональным сервером нейросетей **LM Studio** через стандартный API.
* **🗣 Продвинутый синтез (TTS):** Озвучка на базе модели `TeraTTS` с правильной расстановкой ударений (`RUAccent`).
* **🇬🇧 Англо-Русская фонетика:** Автоматический перевод английских слов в их реальное русское звучание с помощью транскрипции `eng_to_ipa` (чтобы GLaDOS не читала английские термины ломаным транслитом, а произносила их органично).
* **⌨ Управление Push-to-Talk:** Запись активируется только при удержании клавиши `END`.

## 🛠 Требования и зависимости

Для работы скрипта требуются Python 3.10+ и следующие библиотеки:

```bash
pip install numpy soundfile sounddevice keyboard requests faster-whisper TeraTTS ruaccent eng_to_ipa python-dotenv huggingface_hub
```
Важно: Для первого запуска потребуется токен HuggingFace (HF_TOKEN) для загрузки весов моделей. Создайте файл .env в корне проекта:

```dotenv
HF_TOKEN=ваш_токен_huggingface
```

---

## 🚀 Как запустить

1. Запустите LM Studio, выберите и загрузите вашу языковую модель.
2. Включите в ней локальный сервер (Local Server) на порту по умолчанию 1234.
3. Запустите скрипт:

```bash
python glados.py
```
4. Зажмите клавишу END, произнесите фразы и отпустите клавишу. GLaDOS обработает запрос и ответит вам. Для завершения сессии скажите в микрофон "Отбой".
