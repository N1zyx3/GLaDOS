# 🔊 GLaDOS Text-To-Speech Generator

Консольный инструмент для генерации аудиофайлов и озвучивания произвольного текста легендарным русским голосом **GLaDOS** из вселенной Portal. Идеально подходит для создания кастомных реплик, звуковых уведомлений, донатов или интеграции в сторонние проекты.

---

## ✨ Основные фичи

* **💻 Интерактивная консоль:** Вводите любой текст прямо в терминал и мгновенно слушайте результат через динамики или наушники.
* **💾 Сохранение в WAV:** Поддержка записи аудиофайлов напрямую в системную папку «Загрузки» (Downloads).
* **🧠 Умные ударения:** Модуль `RUAccent` автоматически расставляет ударения и правильно обрабатывает омографы для избавления от неестественного акцента.
* **🇺🇸 Фонетическая адаптация:** Скрипт на лету переводит английские слова в точную русскую фонетическую транскрипцию (`eng_to_ipa`). GLaDOS больше не читает английские термины ломаным транслитом, а произносит их мягко и органично.

## 🛠 Требования и зависимости

Перед запуском генератора убедитесь, что у вас установлены необходимые библиотеки:

```bash
pip install TeraTTS ruaccent eng_to_ipa python-dotenv huggingface_hub
```
Важно: Для загрузки весов моделей при первом старте необходим токен от HuggingFace. Создайте файл .env в корневой папке проекта:

```dotenv
HF_TOKEN=ваш_токен_huggingface
```

## 🚀 Использование и синтаксис

Запустите скрипт генератора:

```bash
python "glados (tts).py"
```
### Доступные режимы ввода:
1. **Обычное воспроизведение (В реальном времени):**
Просто введите любой текст в консоль и нажмите Enter. Скрипт озвучит фразу в аудиоустройство по умолчанию.
2. **Режим записи в WAV-файл:**
Используйте управляющий префикс 'ЗАПИСЬ:'. Скрипт сгенерирует аудио и сохранит его в вашу папку «Загрузки».
    * Обычное сохранение (файл запишется под именем glados.wav):
   ```bash
   ЗАПИСЬ: Поздравляю. Не по поводу теста.
   ```
   * Сохранение с указанием собственного имени файла:
   ```bash
   ЗАПИСЬ: test_chamber7.wav: Вот новый куб, на который ты можешь проецировать свое болезненное одиночество.
   ```

Для корректного выхода из программы введите ключевую фразу: конец экспериментам.
