# 🤖 GLaDOS Real-Time Voice Changer (STT + TTS)

Консольный модулятор голоса, превращающий вашу речь в оригинальный голос **GLaDOS** из вселенной Portal в режиме реального времени. Скрипт перехватывает звук с микрофона, распознает текст и мгновенно транслирует его синтезированным голосом в виртуальный аудиокабель для использования в Discord, Telegram или онлайн-играх.

## ✨ Основные фичи

* **🎙 Умная активация голосом (VAD):** Скрипт автоматически калибруется под фоновый шум вашей комнаты при запуске. Больше не нужно нажимать кнопки (Push-to-Talk) — говорите свободно, система сама выделит ваши фразы.
* **🗣 Продвинутый синтез (TTS):** Озвучка на базе модели `TeraTTS` с правильной расстановкой ударений (`RUAccent`).
* **🎛 Аппаратный ресемплинг и защита потока:** Автоматическое приведение звука к стандарту Windows (48000 Гц) и добавление стартовой тишины, чтобы агрессивные фильтры Discord не "проглатывали" первые слоги ваших слов.
* **🇬🇧 Англо-Русская фонетика:** Автоматический перевод английских слов в их реальное русское звучание с помощью транскрипции `eng_to_ipa` (чтобы GLaDOS не читала английские термины ломаным транслитом, а произносила их органично).

## 🛠 Требования и зависимости

### 1. Виртуальный аудиокабель
Для перенаправления звука из скрипта в мессенджеры вам потребуется установить виртуальный кабель. Мы рекомендуем бесплатный **VB-AUDIO Virtual Cable** или **Voicemeeter**.

### 2. Python библиотеки
Для работы скрипта требуются Python 3.10+ и следующие пакеты:

```bash
pip install numpy soundfile sounddevice faster-whisper TeraTTS ruaccent eng_to_ipa python-dotenv huggingface_hub
```
Важно: Для первого запуска потребуется токен HuggingFace (HF_TOKEN) для загрузки весов моделей. Создайте файл ```.env``` в корне проекта:

```bash
HF_TOKEN=ваш_токен_huggingface
```

## 🚀 Как настроить и запустить

1. Установите виртуальный кабель (например, VB-Cable).
2. В настройках **Discord / вашей игры** выберите это виртуальное устройство (например, CABLE Output или Voicemeeter Out) в качестве Микрофона. Рекомендуется также отключить эхоподавление в мессенджере.
3. Запустите скрипт:
    ```bash
    python "glados.py"
    ```
4. **Калибровка:** При запуске скрипт попросит вас помолчать 2.5 секунды. Это нужно для анализа шума кулеров и клавиатуры.
5. **Готово!** Как только вы увидите надпись ```[СЛУШАЮ]```, просто говорите в свой микрофон. Сделайте небольшую паузу (1.5 сек), и GLaDOS мгновенно озвучит вашу фразу собеседникам.
6. Для выхода из программы скажите в микрофон заклинание: "Ты не обычный дурак. Ты спроектированный дурак".
